1- A) Dada G1 : S -> aS | b: 

R: S -> aS
   aS -> aaS
   aaS -> aaab

B) Explique porque você sabe que a derivação terminou.

R: A derivação termina porque em vez de continuar usando S -> aS, usamos a regra S -> b.

2- A) Dada G2: S -> aSb | ε:

R: S -> aSb
   aSb -> aaSbb
   aaSbb -> aaaSbbb
   aaaSbbb -> aaaεbbb
   aaaεbbb -> aaabbb

B) É possível gerar aabbb?

R: Não, porque a cada aplicação é aplicado um "a" e um "b" por vez
